# Docs Detox

AIで下書きした日本語からAI臭を抜き、そのまま公開できる文章に整えるためのClaude Skillです。文書の解毒、という意味で名付けています。

## 何を直すのか

AI臭の正体は、語彙や記号ではなく書き手の不在です。このスキルは表面的な症状と根本的な症状の両方を対象にしますが、修正の重心は常に後者に置きます。

たとえば、次のような文章を捕まえます。

- 見出しだけ妙に大げさになっている。「○○が私たちに教えてくれること」
- 小さい体験を、急に「真理」「美学」「境地」まで膨らませている
- 「AではなくBだ」「3つの観点から」のパターンが続いている
- 全段落が同じ長さ、同じ温度、同じ着地になっている
- 全角ダッシュ、不要な「」、`**` の残骸、装飾絵文字が残っている

なお、書き手の不在そのものはスキルでは治せません。何を見て、何に引っかかり、どこまで言い切るのか。そこを自分で決めることが、結局いちばんの解毒になります。

## 使い方

Claude Codeで `/docs-detox` と入力するか、「docs-detoxで見て」と依頼すると起動します。用途別のプロンプト例を以下に示します。

### レビューだけ

文章を貼って、まず指摘だけ出させます。

```text
この文章を docs-detox の基準でレビューして。
重大な順に、立場、主体、構造、語彙、記号のどこが臭いか指摘して。
各指摘は「問題箇所 / なぜ臭いか / 直すならどうするか」で出して。
まだ書き換えなくていい。
```

### 書き換えまで

意味を変えずに直したいときに使います。

```text
この文章のAI臭を落として。
意味は変えず、立場と主体を優先して直して。
語彙や記号の修正は最後でいい。
修正後に、主な変更点を3つだけ説明して。
```

### 下書きから使う

メモから書かせる場合は、いきなり本文を書かせず、先に主張を確認させます。

```text
このメモを元に記事の下書きを作りたい。
docs-detox の基準で、先に次の3つを確認して。

- 自分は何を言い切るのか
- 反論できるくらい具体的な主張になっているか
- 同じテーマのよくある記事とどこが違うのか

確認してから本文を書いて。
```

### 公開前チェック

最後に軽く見るだけなら、対象を絞ります。

```text
公開前チェックとして、docs-detox で軽く見て。
false agency、命題型H2、一般論化、偏愛語、全角ダッシュ、不要な「」だけ確認して。
問題がなければ「大きな問題なし」とだけ返して。
```

## 修正の優先順位

立場 → 主体 → 構造 → 語彙 → 記号 の順で直します。ダッシュや絵文字だけ直しても、書き手の不在が残っているとAI臭は消えません。

## 採点

5軸を1〜10で採点し、合計が35/50を下回ったら書き直します。

| 軸   | 質問                                     |
| ---- | ---------------------------------------- |
| 立場 | 反証可能な具体的主張があるか?             |
| リズム | 長さ・トーン・結論にムラがあるか?       |
| 主体性 | 誰が何をしたかが明示されているか?       |
| 具体性 | 抽象語で終わらず、固有の文脈に降りているか? |
| 削減 | 削れる箇所はないか?                       |

## 構成

```
docs-detox/
├── SKILL.md              # 大原則 + コアルール + クイックチェック + 採点表
├── references/
│   ├── phrases.md        # 消す候補の語彙（偏愛語、翻訳調、ヘッジ、横文字メタファーなど）
│   ├── structures.md     # 語彙より深い構造のクセ（false agency、命題型H2、両論併記など）
│   └── examples.md       # AI版と修正版の対比
└── README.md
```
