# スライド設計規約（同梱ダイジェスト）

frontend-boilerplateスキルの視覚設計規約から、スライド生成に必要な部分だけを抜粋した自己完結版です。frontend-boilerplateスキルが存在する環境では、そちらのvisual-craft.md / visual-styles.md / tokens.cssを追加で読み、記述が矛盾する場合はそちらを優先します。

---

## 1. 着手前に言語化する4つ

1つでも空欄のまま作ると既定値に落ち、無個性になります。[ux-plan]として記録します。

| 決めるもの | 内容 |
|---|---|
| 目的 | 聴衆に何を持ち帰ってほしいか1つ。複数なら順位を付ける |
| ターゲット | 習熟度・利用場面。密度と語彙の基準になる |
| トーン | 採用する印象2〜3語と避けたい印象1〜3語の両方。実在する参照物を1つ添える |
| 様式 | ダーク × ミニマル × Bentoが既定。読み物寄りならエディトリアルを混ぜる |

強調色の色相は題材のブランドカラーから選び、意味色（危険25・注意78・成功152）から30度以上離します。

## 2. 没入型の規範（既定の外観）

- 地は近黒（明度0.155前後）。灰色ではなく黒に寄せることで内容が発光して見えます
- 骨格（地・器・文字・罫線）はほぼ無彩。彩度は内容（挿絵・コード・主役数値）だけが持ちます
- 骨格側の強調色は1画面に最大2箇所。現在位置や主役を示す用途に限ります
- 枠線より面。階層は面の明度差（段1の地 / 段2の器 / 段3の主役の器）と影2段で作ります。罫線は表の見出し下など意味のある1本に限ります
- 主役を特大にします。表紙は題名だけ、KPIスライドは1つの数値だけを特大にし、字間を強く詰めます。この寸法差が階層を作ります
- 画像の上に文字を載せる場合は下から上への覆い（scrim）を掛けます。これは可読性の機能であり、装飾グラデーションとは別物です

## 3. 12段階調の用途（スライドで使う段）

| 段 | 用途 | テンプレの変数 |
|---|---|---|
| 1 | 画面の地 | --bg |
| 2 | 器（挿絵パネル・コード・バンド・従属セル） | --bg-subtle |
| 3 | 主役の器（Bentoの主セル）・chip | --comp |
| 6 | 意味のある罫線1本 | --line |
| 7 | 箇条書きマーカーなど淡い図形 | --gray-7 |
| 11 | 補足文字（読み飛ばせる情報） | --fg-muted |
| 12 | 本文と見出し | --fg |

守ること: 段2の器を段2の地（扉スライド）の上に置かない。溶けて見えなくなります。

## 4. 活字の役

- 太さは3段まで（400 / 700 / 900）。すべての見出しを太字にすると階層が消えます
- 寸法が上がるほど字間を詰めます（hero: -0.035em、見出し: -0.022em）
- 日本語本文の行間は1.7前後。英字向けの行間のまま組むと詰まって見えます
- 数値はtabular-numsを当て、表では右揃えにします
- 見出しと本文の寸法差は2段以上空けます

## 5. 生成AIの定型癖（禁止）

| 癖 | 代替 |
|---|---|
| 全区画に英大文字の小ラベルを付ける | 原則付けない。使うなら3区画に1つまで |
| 等幅3カラムのカード列 | 面積差2倍以上の1+2分割、横断1列で主従を作る |
| 同型骨格の反復 | 同一骨格は1デッキ最大2回。骨格カタログから分散させる |
| 装飾のグラデーション・光る縁 | 面の階調で表現する。scrimと進捗表示は例外 |
| 絵文字をアイコンに使う | 使わない。図形は情報を運ぶ場合のみ |
| 画像と文の左右交互を3回以上 | 3つ目までに全幅・バンド・表など別の骨格を挟む |
| 紫〜青のグラデーション配色 | 無彩の骨格と強調色1つ |

## 6. 安っぽく見える判定（完成後の自己点検）

| 条件 | 上限 |
|---|---|
| 色数（骨格の灰を除く） | 4色（強調1+意味色。挿絵内の色は内容側なので除外） |
| 角丸の種類 | 2種類（r-4とr-6） |
| 影の段数 | 2段（elev-1とelev-2） |
| 文字の太さ | 3段 |
| 主題の寸法 | fs-3xl以上。fs-xl以下だと目の入口がない |

## 7. スライド固有の制約

- 1スライド1焦点。箇条書きは最大5項目・各2行以内。超えたら分割します
- スライド内スクロールを作りません。表は8行以内で分割します
- 動きは入り減速のみの曲線で240〜400ms。転換の演出以外に常時アニメーションを置きません
- prefers-reduced-motionを尊重します
- 挿絵は「内容」なので彩度を持ってよく、骨格の無彩と共存します
